## 功能

用于管理 Pegasus（天马G）游戏配置文件（metadata.pegasus.txt）。包括：

* 筛选 `metadata.pegasus.txt` 中重复的游戏条目。
* 列出 `metadata.pegasus.txt` 与 ROM 文件相比，缺失/多余的游戏条目。
* 补齐/删除 `metadata.pegasus.txt` 与 ROM 文件相比，缺失/多余的游戏条目。
* 将 天马G/PEGASUS 的游戏列表转换为 Batocera 的 `gamelist.xml` 格式。(待完成)
